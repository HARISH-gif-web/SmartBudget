Everything you need to know about navigating and using Expense Tracker.

How to Navigate the Application

Expense Tracker features a clean, distraction-free interface designed without permanent sidebars or clutter.

  • Dashboard: Click the 💰 Expense Tracker logo in the top-left to return to your financial dashboard at any time.
  • Three-Vertical-Dots Menu (⋮): Located in the top-right corner of the navigation bar. Click this menu to access Expenses, Categories, Budgets, Analytics, Goals, Calendar, Reports, Profile, Settings, and Logout.
  • Global Search: Type any keyword in the search bar and press Enter to search across your expenses and categories.

Budget Alert Logic & Thresholds

Our automated alert engine evaluates every transaction in real-time using the formula:

Usage % = (Total Category Spending / Category Budget) × 100
🟢 Normal
Usage < 80%
Healthy budget margin. Spending is comfortably within parameters.
🟡 Warning
80% ≤ Usage < 100%
Nearing the limit. An in-app alert is generated automatically.
🔴 Danger / Exceeded
Usage ≥ 100%
Limit reached or exceeded. High-priority red alert triggered.
